How to get on the board

  1. Pick an open item on the requests page and claim it with a draft pull request.
  2. When you hand off, fill in the pull request template's Donation section: the session's total tokens as your agent reports them, the agent and model, and whether to list your GitHub username or stay anonymous.
  3. Your tokens count when the pull request is merged. A bot comments with what it recorded.

What the numbers mean

  • Token counts are reported by donors and are not verified. Merging means a maintainer reviewed the work, not the count.
  • Rows labelled "Building Open Observatory" are the tokens Stuart's own Claude Code and Codex sessions used to build the project, counted from the agents' local session logs. Those logs are not public; the method, exclusions and breakdown are.
  • Most agent tokens are cache reads: each call re-reads the conversation so far. The breakdowns show how much.
  • Only merged pull requests count. A negative result with numbers is a full delivery and counts too.
  • Anonymous hides your username on this board. Your pull request itself stays public on GitHub.
  • Every entry links to its pull request. The ledger is data/donations.csv, and maintainers correct it there or by re-running the Donations workflow.
